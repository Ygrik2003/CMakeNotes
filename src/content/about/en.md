My name is Igor. I am a software engineer, and these pages are working notes on CMake: generators, the cache, exporting targets, the things that usually sit in a comment above `target_link_libraries`.

**CMake Notes** is not a course and not a documentation mirror. It is a log of practical cases: why Ninja, when not to poke `CMAKE_BUILD_TYPE` by hand, how not to wreck a build tree by switching generators.

I write in Russian and English. Each note is a pair of Markdown files that share a slug. Math is KaTeX; CMake and C++ listings keep a file name, line numbers, and before/after markers.

Edit this page in `src/content/about/en.md` (and `ru.md`). A new note is a file under `src/content/posts/ru/` and, once translated, a sibling in `src/content/posts/en/`.
